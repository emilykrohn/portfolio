Snake Game

Raylib C++ Video Game

This is a classic Snake game clone built with Raylib and C++. Players navigate the snake around the game board to eat food and grow longer, with movement restricted from immediately reversing direction to prevent accidental instant losses. The game ends if the snake collides with the border or with itself, challenging players to think ahead as the snake grows.

Challenges

One of the biggest challenges was setting up Raylib for the first time and learning how to work with its library and functions, since I hadn't used a graphics library like it before. I also had to adjust to developing in Visual Studio, which was a different workflow than Visual Studio Code, the environment I was more used to, from project configuration to debugging tools, there was a learning curve in getting comfortable with the IDE itself.
